#  Smart Text Editor Buffer System

A console-based Smart Text Editor built in Java as a Data Structures & Algorithms semester project.

##  Author
**Ayesha Tahir** 
BS Computer Science — Semester Project  
Data Structures & Algorithms LAB

##  Features
| Feature | Data Structure |

| Store lines of text | Linked List |
| Undo last action | Stack |
| Redo undone action | Stack |
| Fast line access | HashMap |
| Clipboard history | ArrayList |
| Word search | Binary Search Tree |


```bash
javac Main.java
java Main
```

 Data Structures Used
- **Linked List** — stores each line as a node
- **Stack** — enables undo/redo functionality
- **HashMap** — O(1) line number lookup
- **ArrayList** — clipboard buffer
- **BST** — O(log n) word search
